# Security Policy

## Reporting a Vulnerability

For problems in Nebula's own code (the changes listed in the README), open a GitHub issue on the
[Nebula repository](https://github.com/On-The-GO-Games/On-The-GO-Games.github.io/issues). Do not include exploit details in a public issue
if the problem could put users at risk; write "security" in the title and ask for a private channel instead.

For problems in the upstream proxy code, report them to the
[UseInterstellar project](https://github.com/UseInterstellar/Interstellar/security/advisories/new).
