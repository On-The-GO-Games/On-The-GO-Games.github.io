FAQ

Answers about Nebula and where it comes from.

Where is the source from?

Nebula is a fork of UseInterstellar/Interstellar, an open source web proxy. The upstream project is licensed under the GNU Affero General Public License v3.0 (AGPL-3.0), and this fork is too. Its LICENSE file is in the repository.

What did Nebula change from the original?

The name, logo, default black and blue theme, floating navigation bar, and this FAQ page are new. The upstream popunder ad loader was removed, and the upstream Discord, Patreon, and affiliate links were replaced. The games and apps list, settings, cloaking, and the proxy itself are still the upstream code.

Where can I read the code for Nebula's changes?

The changes are in the Nebula repository. Compare it with the upstream repository to see every change.

Is Nebula free?

Yes. There is no account and no payment. Hosting costs are covered by whoever runs the server.

A game or app does not load. What can I do?

Some games and apps depend on third-party services that block proxies. Try another one, or open it from the Tabs page. Some sites use Cloudflare protection and block proxies entirely.

Can I run my own copy?

Yes. The repository's README explains how to start it in a GitHub Codespace or on your own computer. Because the license is AGPL-3.0, anyone who runs a modified copy as a public website must offer its source code to its users.
