NEBULA

Enter the address of the Nebula server, then open the site. The server address is remembered in this browser.

How do I get a server address?

Codespace: in your Codespace, run pnpm start, then in the Ports tab set port 8080 to Public and copy its address. It stops when the Codespace goes to sleep.

Your computer: run pnpm start in the project folder, then in a second terminal run cloudflared tunnel --url http://localhost:8080. Cloudflare prints an address ending in trycloudflare.com. That address changes each time you restart the tunnel.
